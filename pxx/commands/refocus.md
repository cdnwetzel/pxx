# /refocus — Digest the conversation before /clear (context-rot recovery)

We are about to `/clear` to fight context rot. Before I clear, write a concise digest I can paste back to re-anchor the conversation.

Format:

```
## Task
<one sentence>

## Files touched (and current state)
- path/to/file.py — <one phrase: added X, refactored Y, etc.>
- ...

## Decisions made
- <decision> — <one-phrase reason>
- ...

## Open questions / constraints
- <anything I should re-state after clearing>

## Next 1-2 steps
1. ...
2. ...
```

Be terse. No prose paragraphs. No "Certainly!" or "Here is the digest". Just the digest.
